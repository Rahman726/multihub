# 📸 Photo Store

A beautiful photo gallery app with unlimited photos to browse and discover. Built with vanilla HTML, CSS, and JavaScript.

## Features

- 🖼️ **Unlimited Photos** - Browse endless photos using Picsum Photos API
- 🔍 **Search Functionality** - Search for photos by keyword
- 🎲 **Random Photos** - Discover random photos with one click
- 🏷️ **Category Filters** - Filter by Nature, City, Technology, People, Animals
- 🔍 **Lightbox View** - Click any photo for full-screen view
- ⌨️ **Keyboard Navigation** - Use arrow keys and ESC in lightbox
- 📱 **Responsive Design** - Works great on desktop and mobile
- ⚡ **Lazy Loading** - Efficient image loading
- 🎨 **Modern UI** - Beautiful gradient design

## How to Use

1. Open `index.html` in your web browser
2. Browse photos by scrolling and clicking "Load More Photos"
3. Use the search bar to find specific photos
4. Click "Random Photos" for a fresh set
5. Use category filters to browse by theme
6. Click any photo to view it in full-screen lightbox
7. Use arrow keys (←/→) or click arrows to navigate in lightbox
8. Press ESC or click outside to close lightbox

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- [Picsum Photos API](https://picsum.photos/) - Free placeholder photos

## No Installation Required

This is a static web app - just open index.html in your browser and start browsing!
